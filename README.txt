🚀 QUICK START
=======================================================

Option A: Run with Local Database Server (Recommended!)
1. Open terminal in this folder:
   cd c:\Users\abimanyu\Downloads\mimi_todo_app
2. Start the server:
   npm start
   (or: node server.js)
3. Open your browser to:
   http://localhost:3000

All your tasks, streaks, subtasks, notes, and focus stats will automatically save to:
`data/database.json`

Option B: Run Standalone Offline
Double-click `index.html` to run in any browser. It will use browser LocalStorage and automatically sync whenever the server is started!
